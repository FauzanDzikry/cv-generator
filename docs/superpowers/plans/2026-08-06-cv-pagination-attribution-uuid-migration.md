# CV Pagination, Attribution, Relational Data, and UUID Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Membuat preview CV A4 yang sticky dan responsif, pagination deterministik yang sama dengan PDF unduhan langsung, attribution pada setiap halaman, data CV relasional dengan hard delete cascade, serta UUIDv7 pada seluruh identifier domain.

**Architecture:** Satu renderer halaman A4 menjadi sumber output preview dan PDF. Renderer melakukan pengukuran DOM dua tahap pada lebar konten A4 yang sebenarnya, lalu mengemas blok semantik secara greedy dengan aturan keep-with-next dan fallback pemecahan teks hanya untuk blok yang lebih tinggi dari satu halaman. Backend tetap menerima dan mengirim satu payload CV agregat; controller menyimpan parent dan delapan relasi one-to-many dalam satu transaction dengan strategi replace-all karena child record tidak memiliki CRUD independen.

**Tech Stack:** Laravel 12, PHP 8.2+, PostgreSQL 17, SQLite untuk test, Inertia 2, React 19, TypeScript 5.7, Tailwind CSS 4, `html2pdf.js` yang sudah terpasang, PHPUnit 11, dan Playwright Chromium.

## Global Constraints

- Bahasa UI yang sudah ada tetap dipertahankan; attribution harus persis `Generated by cvgenerator.zandev.my.id`.
- Kertas selalu A4 portrait: lebar `210mm`, tinggi `297mm`.
- Margin awal adalah atas `10mm`, kanan `10mm`, bawah `10mm`, kiri `10mm`.
- Empat konstanta `MARGIN_TOP`, `MARGIN_RIGHT`, `MARGIN_BOTTOM`, dan `MARGIN_LEFT` adalah satu-satunya sumber margin preview, PDF, dan CSS print.
- Pengguna tidak dapat mengubah margin; developer dapat mengubah empat konstanta tersebut.
- Footer setiap halaman menampilkan attribution di kiri dan nomor halaman berformat `X of Y` di kanan, tanpa kata `Page`.
- Margin guide hanya terlihat pada preview, berwarna merah/theme red dengan opacity rendah, `pointer-events: none`, dan tidak masuk PDF/print.
- PDF diunduh langsung tanpa dialog print menggunakan dependency `html2pdf.js` yang sudah ada.
- Chromium terbaru adalah target utama; Firefox dan Safari divalidasi secara best effort.
- Sticky preview hanya aktif pada desktop `lg`/lebar minimal 1024 px; layar yang lebih kecil memakai layout bertumpuk.
- Gunakan UUIDv7 buatan aplikasi melalui trait Laravel `HasUuids`; PostgreSQL memakai tipe native `uuid`.
- UUID hanya menggantikan identifier domain dan referensinya: `users`, `cv.cv_data`, delapan tabel detail CV, dan `sessions.user_id`. PK internal Laravel `jobs`, `failed_jobs`, dan `migrations` tetap mengikuti schema framework.
- Tidak ada kompatibilitas URL atau ID integer lama setelah cutover.
- Data lokal tetap dipertahankan dan CV legacy ID `1` wajib berhasil dibackfill.
- Seluruh penghapusan CV adalah hard delete; `users -> cv_data -> detail CV` memakai `ON DELETE CASCADE`.
- Tidak ada CRUD independen untuk child record. Payload frontend tetap satu dokumen CV dengan nested arrays.
- `sort_order` tetap digunakan karena `created_at` saat ini berpresisi detik dan tidak dapat menjamin urutan item yang dibuat bersamaan.
- Tidak menambah abstraction, dependency, atau tabel di luar kebutuhan plan ini.

## 2. Analisis Akar Masalah

### Card preview tidak mengikuti viewport

- Wrapper preview hanya memiliki `md:w-1/2`.
- Card memakai `h-full`, sehingga tinggi mengikuti parent flex yang setinggi seluruh form, bukan viewport.
- `overflow-auto` tidak memiliki tinggi/max-height pembatas.
- Tidak ada `sticky`, `top`, atau `min-h-0` pada rantai flex card.

### Ruang kosong dan page break terlalu cepat

- `PAGE_HEIGHT = 890` adalah angka perkiraan dan tidak berasal dari content box A4 hasil render.
- Tinggi teks dihitung dari `text.length / charsPerLine`, sehingga mengabaikan word wrapping, font metrics, date column, photo, link, dan justification.
- Tinggi header/section/item/bullet memakai magic number yang tidak sama dengan computed CSS.
- `marginThreshold` memakai nilai berbeda `80`, `0`, `-100`, dan default `15`; akibatnya kapasitas halaman berbeda per section.
- Parameter `bulletHeight` dan helper `calculateItemHeight()` tidak mengontrol keputusan akhir.
- Item header dapat dimasukkan sebelum pengecekan intro/bullet, sehingga header bisa yatim pada halaman sebelumnya.
- Skills, languages, dan additional info memakai algoritme khusus yang berbeda.
- `overflowY: hidden` pada `.cv-page` menyembunyikan kesalahan estimasi alih-alih memperbaikinya.

### Preview, print, dan PDF tidak sinkron

- Preview memakai Tailwind + inline styles + transform zoom.
- Print iframe membangun ulang sebagian utility Tailwind dan menimpa typography/spacing.
- `@page margin: 1cm` dan `.cv-page padding: 1cm` menciptakan dua sumber margin.
- `.html2pdf__page-break` dan `page-break-after` dipakai bersamaan.
- Hidden export memakai `display: none`, sehingga tidak dapat menjadi measurement surface untuk export langsung.

### Data dan ID

- JSON mempertahankan order, tetapi tidak menyediakan FK, row-level index, atau integritas per item.
- Normalisasi dapat menambah query; mitigasinya adalah eager loading hanya pada show/edit dan tidak memuat child pada index.
- `created_at` tidak cukup sebagai urutan karena beberapa child dapat dibuat dalam detik yang sama. `sort_order` harus ditulis backend dari index array.
- Route, controller, TypeScript, signed email verification, dan session user reference masih mengasumsikan numeric ID.

## 3. Keputusan Teknis Final

### Pagination

Pendekatan yang dipilih adalah two-pass DOM measurement:

1. Bentuk daftar blok semantik dari data CV.
2. Render blok ke measurement surface offscreen pada content width A4 yang sama dengan halaman final.
3. Tunggu `document.fonts.ready` dan `HTMLImageElement.decode()`.
4. Ukur blok dan content box menggunakan `getBoundingClientRect()` dalam coordinate system yang sama.
5. Pack blok secara greedy. Halaman baru dibuat hanya jika blok berikutnya benar-benar tidak muat.
6. Terapkan `keepWithNext` pada section heading dan item heading.
7. Pecah item panjang pada batas paragraph/bullet; ulangi item heading dengan suffix `(continued)`.
8. Bila satu paragraph/bullet sendiri lebih tinggi dari satu content box, pecah pada word boundary menggunakan binary search terhadap hasil DOM measurement.

Pendekatan yang ditolak:

- Menyetel ulang magic number: tetap rapuh terhadap font dan wrapping.
- Menyerahkan seluruh pagination ke CSS `break-inside`: tidak cukup untuk menghindari orphan dan hasil `html2canvas` lintas-browser.

### Penyimpanan agregat

Frontend tetap mengirim nested arrays tanpa child ID. Backend:

1. Validate parent dan seluruh nested keys.
2. Ambil field parent.
3. Simpan/update `cv_data`.
4. Untuk setiap relasi, hard-delete child lama dan `createMany()` child baru dengan `sort_order` dari index array.
5. Jalankan seluruh operasi dalam `DB::transaction()`.

Replace-all dipilih karena child tidak memiliki endpoint/identity publik, ukuran array kecil, dan jauh lebih sederhana daripada differential sync. Jika kelak satu CV mempunyai ratusan child atau child memiliki referensi eksternal, ganti dengan UUID-aware upsert tanpa mengubah payload agregat.

### Target schema child

Semua child memiliki `id uuid primary key`, `cv_data_id uuid`, `sort_order smallint`, timestamps, unique index `(cv_data_id, sort_order)`, dan FK cascade. Field konten nullable agar form dinamis dapat menyimpan baris parsial seperti perilaku JSON sekarang.

| Table | Content columns |
|---|---|
| `cv.work_experiences` | `company`, `company_location`, `position`, `location_type`, `start_date`, `end_date`, `description`, `is_current` |
| `cv.educations` | `institution`, `degree`, `field`, `start_date`, `end_date`, `description` |
| `cv.skills` | `name` |
| `cv.portfolios` | `title`, `link`, `description` |
| `cv.certifications` | `name`, `organization`, `start_year`, `end_year`, `is_time_limited`, `description`, `credential_id` |
| `cv.languages` | `language`, `level` |
| `cv.accomplishments` | `description` |
| `cv.organizations` | `name`, `position`, `start_date`, `end_date`, `is_current`, `description` |

Gunakan `date nullable` untuk date, `smallInteger nullable` untuk year, `boolean` untuk flag, `text nullable` untuk description, dan `string nullable` untuk value pendek.

    ccu.column_name AS referenced_column,

JOIN information_schema.key_column_usage kcu

JOIN information_schema.constraint_column_usage ccu

## 8. Risiko Teknis Utama

| Risiko | Dampak | Mitigasi |
|---|---|---|
| DOM measurement berubah setelah font/photo load | Page count flakey | Await fonts/images; separate measurement surface; signature guard |
| html2pdf raster berbeda dari browser DOM | Perbedaan kecil atau file besar | Canonical exact-A4 export tree, scale 2, Chromium target utama |
| Keep-with-next menyisakan ruang | Gap yang disengaja | Test membedakan gap valid dari next movable block yang sebenarnya muat |
| Paragraph tunggal lebih tinggi dari page | Overflow/clipping | Word-boundary fallback dengan DOM binary search |
| Delapan eager-loaded relations menambah query | Show/edit lebih lambat | Index tidak eager load; show/edit memakai bounded 9-query pattern |
| Replace-all child mengubah UUID | Referensi child tidak stabil | Child ID tidak diekspos; upgrade ke upsert hanya jika ada consumer baru |
| UUID swap merusak session/signed URL | Logout/verification failure | Invalidate session saat cutover dan regression test signed URL |
| Drop legacy menghilangkan rollback cepat | Kehilangan mapping | Pertahankan legacy sampai Phase 12; validated `pg_dump` sebelum Phase 13 |

## 9. Final Definition of Done

- Preview A4 memakai ukuran dan empat margin constants yang sama dengan export.
- Preview card sticky dan viewport-bounded hanya pada desktop.
- Tidak ada content overflow; break hanya terjadi ketika next semantic block tidak muat atau keep-with-next berlaku.
- Preview rerender deterministik dan page count sama dengan PDF.
- PDF langsung terunduh tanpa dialog/side effect save.
- Setiap halaman memiliki attribution dan `X of Y`; margin guide hanya preview.
- Delapan JSON arrays telah menjadi tabel one-to-many dengan UUIDv7, `sort_order`, timestamps, dan cascade FK.
- Payload frontend tetap agregat dan user tidak perlu melakukan child CRUD.
- CV dan user menggunakan UUID string end-to-end; internal Laravel IDs tidak diubah.
- CV ID `1` berhasil dibackfill tanpa perubahan value/order.
- Delete CV dan delete user melakukan hard cascade; tidak ada `deleted_at`.
- PHP tests, TypeScript, Playwright Chromium, targeted lint/format, SQL numeric-ID audit, FK audit, dan orphan audit seluruhnya lulus.
- Tidak ada fallback legacy, magic page height/margin, duplicate print CSS, atau numeric domain ID tersisa.
